# RUMLE WEB 0.3

Оригинальная браузерная open-world игра в криминальном сеттинге города **Новоград**.

**Не связана** с Rockstar Games, GTA или любыми их торговыми марками, персонажами, картами и музыкой.

## Что исправлено и реализовано в 0.3

### Исправление сборки
- Добавлен алиас `@/*` в `tsconfig.json` (`baseUrl` + `paths`)
- Это устраняет ошибки `Module not found: Can't resolve '@/components/GameWorld'` и `@/components/OnlineLobby`
- Сохранены Next.js 15, TypeScript, React Three Fiber, PeerJS

### Игровой контент
- Кинематографичное главное меню с 3D-фоном города
- Режимы: одиночная игра и RUMLE ONLINE
- Процедурный город Новоград: кварталы, дороги, разметка
- Управляемый персонаж (WASD + мышь, бег на Shift, pointer lock)
- Автомобили (в том числе полицейские с маячками)
- Пешеходы с простым ИИ
- Базовый PeerJS-мультиплеер: создание комнаты, подключение по ID, чат
- Индивидуальные данные игроков (деньги/инвентарь не синхронизируются, передача денег запрещена)

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

### Production-сборка

```bash
npm run build
npm start
```

### Проверка TypeScript

```bash
npm run typecheck
```

## PeerJS (онлайн)

По умолчанию используется публичный сервер `0.peerjs.com`.  
Для продакшена рекомендуется свой PeerServer. Переменные — см. `.env.example`.

## Статус

Это **рабочий прототип**, а не готовая AAA-игра.  
Следующие этапы: полноценный синк позиций игроков, физика транспорта, уровень розыска и преследования, миссии, магазины/гаражи, смена времени суток и погоды, сохранения.
