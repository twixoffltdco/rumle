# RUMLE WEB 0.4 — Global Gameplay Foundation

Оригинальная браузерная open-world игра в городе **Новоград**.

**Не связана** с Rockstar Games, GTA VI или любыми их торговыми марками, персонажами, картами, моделями и музыкой.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

```bash
npm run build   # production
npm start
npm run typecheck
```

## Реализовано в 0.4 (реально работает)

### Архитектура
- Модульный код: Zustand store, типы, каталог транспорта, отдельные UI-компоненты
- Сохранения через localStorage (деньги, здоровье, миссии, качество графики)
- Настройки качества (low / medium / high) влияют на количество объектов и тени

### Мир
- Расширенный процедурный Новоград: центр, спальные районы, монументальный комплекс (оригинальный), набережная
- Динамический день/ночь (ускоренный цикл)
- Погода: ясно, облачно, дождь, туман (случайные смены)
- Освещение и небо зависят от времени суток

### Игрок
- Мужской / женский персонаж (выбор в настройках)
- Управление: WASD, мышь (pointer lock), Shift — бег
- Здоровье и выносливость
- Деньги, уровень розыска (0–5)

### NPC и полиция
- Пешеходы с состояниями: ходьба, простой idle, бегство при высоком розыске, «вызов полиции»
- Полицейские автомобили реагируют на уровень розыска и преследуют игрока
- Звёзды розыска в HUD

### Транспорт
- Каталог оригинальных марок: Vostok, Aura, VolgaX, Raiser, Nord, Vector, Orion, Kresta
- Классы: седаны, SUV, спорт, суперкары, мото, грузовики, автобусы, полиция
- Модели на дорогах + полицейские патрули

### Интерфейс
- Полноценный HUD (деньги, время, погода, розыск, полоски здоровья/выносливости, трекер миссий)
- Смартфон (P): карта-заглушка, задания, контакты, банк, настройки качества
- Система миссий (принять / завершить, награда деньгами)

### Online
- PeerJS: создание комнаты, подключение по ID, чат
- Вход в общий мир
- Экономика и инвентарь строго индивидуальные (переводы запрещены)
- Синхронизация позиций игроков и транспорта — ещё в разработке (честно указано в UI)
