# RUMLE WEB 0.6 — Night City Visual Pass

Оригинальная браузерная open-world игра (Новоград). Не связана с Rockstar / GTA.

## Фокус 0.6
Визуал по атмосфере референсов: ночной город, мокрый асфальт, окна с подсветкой, неон, фонари, полицейская машина с маячками, не «серые кубы».

## Играбельно
- F — сесть/выйти, WASD — езда/ходьба, P — телефон
- Розыск, миссии с точками, сохранения, PeerJS online (чат/комнаты)

```bash
npm install && npm run dev
```

```bash
npm run build && npm start
```
