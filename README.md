# RUMLE WEB 0.7

Оригинальная браузерная open-world игра (Новоград). **Не** GTA и **не** продукт Rockstar.

## Новое в 0.7
- **Пролог** при новой игре
- **Маска (G)** — влияет на опознание
- **Память полиции** по маске и одежде; смена облика → «не опознан», розыск падает быстрее, погоня слабее
- **Магазины одежды** в мире → телефон → Одежда
- **Новоградская цитадель** — крупный свой монумент на севере центра

## Управление
WASD · мышь · F авто · **G маска** · P телефон · Shift бег

```bash
npm install && npm run dev
npm run build
```
